MultiMalModPy Documentation

Documentation of MultiMalModPy, a novel programmatic framework for running three individual-based malaria transmission models.

Contribute to its development

MultiMalModPy is an open-source framework to which anyone is welcome to contribute. Check out the GitHub repository for all the source code, open issues etc. and send us a pull request. For new feature requests, please check out the open issues and open a new one if a related one does not already exist.
