MultiMalModPy Documentation

Documentation of MultiMalModPy, a novel programmatic framework for Multi-Malaria-Model simulation framework.

MultiMalModPy includes the following three models:
Epidemiological Modeling of Disease Software (EMOD) malaria
OpenMalaria
malariasimulation

Content

  • GETTING STARTED: General information for each of the three models and comparison of features.
  • USER GUIDE: Instructions and information on how to use the framework and methods used
  • API: List of framework-specific functions and scripts
  • ABOUT: Information and links specific to each of the models included in the framework
