  • Simulation outputs:
    • generated simulation input and raw output files

Shell script processes

Collection of exemplary sh files generated by the framework. These can be used for manual launching or as example of steps included in the process.

1) Launch specific simulation types
run_calib_sims.sh
run_launch_sim.sh

2) Simulation runs
run_sim_EMOD.sh
run_sim_malariasimulation.sh run_sim_OpenMalaria.sh

3) Postprocessing
run_analyzer_EMOD.sh
run_analyzer_malariasimulation.sh
run_analyzer_OpenMalaria.sh

4) Generate default plots (optional)
run_relationship_plots.sh
run_agecurves_plots.sh
run_timeseries_plots.sh

Example: 

#!/bin/bash
#SBATCH -A b1139
#SBATCH -p b1139
#SBATCH -t 01:00:00
#SBATCH -N 1
#SBATCH --ntasks-per-node=1
#SBATCH --mem-per-cpu=1G
#SBATCH --job-name="run_calib"
#SBATCH --error=log/run_calib_%j.err
#SBATCH --output=log/run_calib_%j.out

ml singularity/3.8.1 
ml python/3.8.4
source /projects/b1139/environments/emodpy_om/bin/activate

python launch_sim.py  --models EMOD malariasimulation OpenMalaria -r test
