
## simulations

Simulation scripts for different sub-analysis and scenarios.
Each simulation script _will have_ the option to run with or without the vector model (currently for perennial seasonality only).


#### Scenarios:
- `launch_baseline_noCM.py`: most basic simulation without any interventions or treatment of cases
- `launch_baseline.py`: includes treatment of cases (fixed value)
- `launch_case_management.py`: includes varying treatment of cases for clinical and severe cases and by age
