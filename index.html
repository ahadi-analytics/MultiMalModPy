MultiMalModPy: A Python Framework for Multi-Model Malaria Simulation¶

A HPC-oriented framework in Python and R that enables users to interact with EMOD-malaria, malariasimulation, and OpenMalaria.
MultiMalModPy is designed for modelers already familiar with one of these models, as well as for those who wish to learn more about all three models in a unified and accessible approach. It allows to run the models in combination or alone for model characterization and comparison.

This documentation provides
1. Model Reference Links: High-level descriptions of each model, including links to their original source documentation for further reference.
2. User Guidance: Detailed instructions, best practices, and resources tailored to facilitate both introductory learning and advanced usage of MultiMalModPy. This guide is a supplementary resource and should be used alongside the official documentation of the three models.
