Contributing to MultiMalModPy¶

If you see any errors on the documentation or have issues using the code please report an issue.
Pull-requests from forks are welcome as well if you would like to contribute to make MultiMalModPy better.

Online documentation edits:
If you are a developer or advanced user, click on ‘Edit on GitHub’ and make the required edits. For developers, how to update the online documentation is described in the ./docs/README.md.
