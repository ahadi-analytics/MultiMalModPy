Model parameters¶

This page provides a high-level summary of the simulation parameters types, format and definition used across the three models.

❗ Please refer to each model's source documentation. The information provided here is indicative only and may not reflect the latest updates of each model.


  • EMOD includes a large and detailed set of parameters that control vector biology, host immunity, climate effects, and simulation configuration. These parameters are mostly configured via JSON or campaign scripts.
  • malariasimulation parameters are implemented in R and used to define host immunity, infection progression, and clinical outcomes. Emphasis is placed on age-structured immunity and probabilistic outcomes.
  • OpenMalaria parameters are implemented in XML.
