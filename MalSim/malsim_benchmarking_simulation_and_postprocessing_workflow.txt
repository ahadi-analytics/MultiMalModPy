#--- Scripts

1. malsim_benchmarking_exercise.R: 

  This script contains all the code necessary to take the scenarios.csv, run the simulations and process the outputs. The functions it loads/depends on are stored in the folder R_functions, described below.

2. run_simulations.R

   The run_simulations() function takes a data frame of simulation parameters, loadable from a .csv template and where each row represents a single simulation, and a number of time steps to simulate over, and sets up and runs malariasimulation simulations using the package's public functions. The function currently allows the user to switch between a seasonal and perennial seasonal setting, establish a clinical treatment coverage, and specify an initial EIR to calibrate to, but future versions can integrate far more user-options, tuneable through additional columns in the input .csv/data frame.

3. malsim_post_processing.R

   The malsim_post_processing() function wraps together the steps required to take the raw outputs from run_simulations() and return/save data frames with the required benchmarking exercise variables of interest, aggregated monthly and annually, as .csv's. The function first uses combine_malsim_outputs() to take the individual malariasimulation data frames and create a single data frame. The add_dates_and_prevalence() function then appends columns which indicate which month and year each day of the simulation falls on (assuming the simulation starts on 01/01 of any given year), and columns containing the prevalence in each age group rendered (number of detected cases / number of people per age group). The data frame is then converted to long-form using the convert_malsim_to_long() function, before summarise_by_month() and summarise_by_year() are used to produce the monthly- and annually-aggregated data frames. Finally, the function stores the monthly- and annually-aggregated data frames as .csv's and then returns a list containing the data frames.

4. add_dates_and_prevalence.R

   The add_dates_and_prevalence() function first adds a column assigning each time step a month (as an integer from 1-12), using the number of days per month (a vector input of length 12). A second column is added to assign each timestep a year in the simulation. Finally, a series of 5 columns are added representing the prevalence in the age groups 0-5, 5-10, 10-15, 15-20, and 2-10, calculated by dividing the number of detected cases in that age group and time step by the number of people in that age group and time step. The function returns the modified data frame, which now has an additional 7 columns.

5. combine_malsim_outputs.R

   The combine_malsim_outputs() function simply loops through the raw output from run_simulations() (a list of length two in which the second index stores the individual simulation data frames from the parameterised simulation runs) and creates a single, combined data frame by binding each data frame using row-binding. The function accepts a list of raw outputs and returns a single data frame object.

#--- Order of Operations:

1. Set the working directory to where the R functions are stored and load them in using the for loop

2. Set the minimum and maximum ages, in days, of the age classes you want to render values for. In
   the current exercise these are 0-5, 5-10, 10-15, and 15-20.

3. Create a vector containing the number of days in each month in a non-leap year (e.g. 2023) to be
   used to assign the correct month to each day in the simulation (assuming simulations start on
   01/01/XXXX)
   
4. Set the number of years to simulate over
   
5. Load in the .csv of parameters into a data frame (e.g. using the read.csv() function). Each row in
  data frame represents the parameters for a single simulation, so the number of rows contained within
  the data frame represents the number of simulations to be run.

6. Run the simulations using the run_simulations() function. The output is a list of length two. The
   The first entry contains each of the malariasimulation parameter lists generated for each row of
   the input .csv/data frame. The second contains each of the output data frames generated by the
   malariasimulation model.
   
7. Run the malsim_post_processing() function to convert the raw outputs from run_simulations into the
   monthly-aggregated and annually-aggregated data frames. Currently this returns a subset of those
   we are aiming for, but we can expand/amend this as necessary going forward.

8. I've commented the lines out because I wasn't sure how you'd get the functions to work within the
   python framework, but the last two lines output .csv's of the monthly- and annually-aggregated data
   frames.
