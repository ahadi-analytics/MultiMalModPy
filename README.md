# MultiMalModPy

Documentation of Multi-Malaria-Modelling Python Framework.

Using [mkdocs](https://www.mkdocs.org/getting-started/)
To view and edit documentation:

```
cd MultiMalModPy
mkdocs serve
```

"_Open up http://127.0.0.1:8000/ in your browser, and you'll see the default home page being displayed:_"

and
```
mkdocs build
```

Note, the source code to share along with paper 1 for public view will be 
added to this repository later on.
