
# Citation

## Citing MultiMalModPy

If you use MultiMalModPy in your research, please cite:

1. **Software:** MultiMalModPy, including the version used.
2. **Framework publication:** The accompanying manuscript describing the software architecture and implementation.

### Software citation

**MultiMalModPy: Multi-Malaria-Modeling Python Framework**

#### Suggested citation

Richter R., Cavelan A., Brewer T, Shattock A., Nekkab N., Winskill P., Penny M., Gerardin J., Runge M. (2026). *MultiMalModPy: Multi-Malaria-Modeling Python Framework* (Version 1.0.0) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23282932

#### Software availability

- **Zenodo:** [10.5281/zenodo.23282932](https://doi.org/10.5281/zenodo.23282932)
- **GitHub:** [MultiMalModPy repository](https://github.com/ahadi-analytics/MultiMalModPy)
- **Documentation:** [MultiMalModPy Documentation](https://ahadi-analytics.github.io/MultiMalModPy/)

The Zenodo record provides an archived software release. The latest version, including updates and bug fixes, is available from the [GitHub repository](https://github.com/ahadi-analytics/MultiMalModPy/releases).
When citing MultiMalModPy, please specify the version used to support reproducibility.
