# Contributing to MultiMalModPy 

If you see any errors on the documentation or have issues using the code please report an issue.  
Pull-requests from [forks](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo) are welcome as well if you would like to contribute to make MultiMalModPy better.
