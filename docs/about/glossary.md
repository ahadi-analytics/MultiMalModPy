# Glossary


**Burnin**  
: A time period used to warm up the model, reaching equilibrium or initializing population immunity or the vector model. 
  Outputs are typically not monitored during this phase, and handling varies across models.

**experiment ID**  
: A unique identifier assigned to each simulation in EMOD.

**manifest**  
: The Python script where user-specific configurations, such as paths and installed software versions, are defined (term adopted from IDMTools).

**MultiMalModPy**  
: Multi-Malaria-Modeling Framework

**scen_df / scenario csv**  
: A CSV file containing all unique parameter combinations for a simulation scenario. Generated in `launch_sim.py`.
